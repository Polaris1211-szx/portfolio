# Shu Zixuan — Selected Technical Projects

This repository is a clean portfolio snapshot of selected AI, information-retrieval, and reasoning-system projects. It contains final source files and project documentation only; intermediate Git history, caches, local secrets, and temporary build artifacts are intentionally excluded.

## Projects

### [Folio — AI Accounting Document Collection and Review Agent](projects/folio-accounting-agent/README.md)

An AI-assisted workflow for accounting firms to request, classify, review, reconcile, and follow up on monthly supporting documents. Personal work included generating the 2,000-case synthetic evaluation dataset, participating in SFT and DAPO training/tuning, and reproducing the model API integration.

### [TechJam Conversational Shopping Agent](projects/techjam-shopping/README.md)

An offline-first multi-turn shopping agent for a 50,000-item catalog. Personal work focused on candidate retrieval and ranking optimization using BM25, query variants, category anchors, RRF, and evidence-aware reranking.

### [Sudoku Logic Inference System](projects/sudoku-logic-inference/README.md)

An interactive Python and Streamlit system that encodes Sudoku constraints as CNF and Horn rules, supports forward and backward chaining, and exposes explainable proof traces through a browser interface.
